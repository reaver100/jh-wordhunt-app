# 가족 미니게임

한 폰을 넘겨가며 온 가족이 겨루는 30초 미니게임 모음입니다.
(이 저장소는 원래 '영어 단어 사냥'이었고, 같은 주소에 미니게임으로 교체했습니다.)

- 주소: https://reaver100.github.io/jh-wordhunt-app/
- 서버·네트워크 없음. 설치 후 비행기모드에서도 돌아갑니다
- 기록은 폰 안(localStorage)에만 저장됩니다

## 게임
| 게임 | 내용 | 승리 조건 |
| --- | --- | --- |
| ⚡ 반응 속도 | 초록으로 바뀌면 바로 탭, 5번 평균 | 빠를수록 |
| 👆 10초 연타 | 10초 동안 두드린 횟수 | 많을수록 |
| 🧠 불빛 기억 | 불빛 순서를 따라 누르기 | 오래 버틸수록 |
| ⏱️ 정확히 10초 | 시계 없이 10초를 세어 멈추기 | 오차가 적을수록 |
| 🎨 색깔 함정 | 글자가 아니라 글자의 '색'을 고르기, 20초 | 점수 높을수록 |

게임마다 순위에 따라 10·7·5·3·2·1점을 받고, 합계로 우승자를 가립니다.
