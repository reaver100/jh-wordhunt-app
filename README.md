# 영어 단어 사냥

카메라로 집 안 물건을 찍으면 폰 안의 AI(MobileNet)가 알아보고 영어 이름을 알려주는 아이들용 앱입니다.

- 주소: https://reaver100.github.io/jh-wordhunt-app/
- 서버 없음 — 기록은 폰 안(localStorage)에만 저장됩니다
- 홈 화면에 추가하면 앱처럼 씁니다 (PWA)

## 기능
- 사물 인식 → 영어 단어 + 한국어 + 발음 듣기
- 도감: 찍은 사진과 함께 단어 수집, 배지(10·30·60·100개)
- 오늘의 목표 5개 (매일 바뀜)
- 복습: 모은 단어로 4지선다 퀴즈

## 파일
| 파일 | 설명 |
| --- | --- |
| `index.html` | 화면 구조 |
| `app.js` | 카메라·인식·도감·퀴즈 로직 |
| `dict.js` | 영어↔한국어 사전 (약 700단어) + 품종을 기본 단어로 묶는 규칙 |
| `style.css` | 디자인 |
| `sw.js` | 오프라인 캐시 (AI 모델은 한 번 받은 뒤 캐시에서 사용) |

## 참고
- 첫 실행 때 AI 모델(약 14MB)을 내려받습니다. 와이파이에서 첫 실행을 권합니다.
- 카메라 권한이 필요하고, HTTPS에서만 동작합니다.
